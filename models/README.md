# 模型权重

将训练好的 YOLO11 **目标检测**权重放在本目录的 `best.pt`，或在 `.env` 中设置
`MODEL_PATH` 为其他路径。平台读取 `model.names`，不会固定业务统计类别。

当前 `best.pt` 已替换为用户本机完成训练的 SHWD 二分类模型（`helmet`、`no_helmet`），
训练 50 轮，最佳验证指标对应第 42 轮。独立测试集 mAP50 为 85.22%，
测试截图在 0.50 下正确识别 2 顶安全帽与 2 颗裸头，0.25 下仍有文字区域误检。
完整指标和接入记录见 [模型评估](../docs/trained-model-evaluation.md)。

此前使用的骑行头盔模型来自本地 BikesHelmets 数据集的微调结果。

源训练参数为 YOLO11n、640 输入尺寸、50 epochs；这里只复用已有权重，不进行重新训练。
训练集 1483 张、验证集 129 张、测试集 59 张的文件名都来自 `BikesHelmets`。
类别名称相同不代表模型适用于工地安全帽；已复现工地图片的漏检与截图文字区域的误检。
**这份旧权重不适合用作工地安全帽检测的验收模型。** 需要使用匹配工地场景的
数据重新训练或替换为已验证的工地模型。不能仅靠提高阈值解决场景不匹配。

`best.json` 记录训练场景和已知问题，并通过 SHA-256 与当前权重绑定。
更换 `.pt` 文件后旧说明会自动失效；新模型可以提供同名 `.json` 说明文件。
当前 `best.pt` 和 `best.json` 随仓库提供；其他权重、通用预训练下载及旧模型备份被排除。
只使用可信来源的模型文件。

本机训练时使用独立的 `pretrained/yolo11n.pt`（COCO 通用 80 类、约 2.6M 参数），
用于重新学习 SHWD 的两个类别。它不是平台目前的骑行微调模型。
数据、手动训练、测试集评估和安装方法见 [训练指南](../docs/training.md)。
训练默认输出 `runs/helmet_shwd_m1/weights/best.pt`，不会自动覆盖本目录的旧模型。
本次评估后已运行安装脚本，旧权重备份在本机 `backups/` 中，不随仓库提供。
