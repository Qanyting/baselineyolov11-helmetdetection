# 界面设计

采用 frontend-design Skill，并以任务书的简约、现代、专业和低饱和要求为准。

- 背景 `#F3F6F7`，内容表面 `#FFFFFF`，文字 `#243339`。
- 侧栏 `#25363C`，操作色 `#216A67`，分隔线 `#E2E9EC`。
- 字体采用 macOS 本地 Avenir Next 和苹方，Windows 回退到微软雅黑，无外部字体请求。
- 232 px 固定侧栏，主区域左对齐；上传与使用说明、原始与结果媒体分栏。
- 品牌使用安全帽轮廓与检测框作为一个视觉焦点；其余区域依靠间距、对齐和清晰的信息层次。
- 实际检测数量、模型就绪状态和上传限制使用真实数据；空状态引导上传。
- 输入、等待、错误、删除确认均给出明确反馈，尊重减少动态效果的系统偏好。

审查调整：不增加大面积渐变、装饰动画或虚构检测数据。统计采用一行概览，
检测入口使用两张有用途区分的卡片，避免所有内容套用同一种卡片结构。
